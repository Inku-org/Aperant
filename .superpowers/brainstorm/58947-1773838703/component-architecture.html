CORE ENGINE

• start() / stop() lifecycle
• Manages poller + outbound queue

• Fetches issues updated since lastSyncAt
• Diff detection (new, changed, deleted)
• Configurable interval

• Enqueue events from agent pipeline
• Batch + flush to Linear API
• Persist to disk, retry with backoff
• Rate limit tracking

Engine Lifecycle

When does the sync engine run?
▶ START — When a project with Linear enabled is opened
⟳ RUNNING — Polls on interval, processes outbound queue continuously
⏹ STOP — When project is closed or Linear is disabled
💾 PERSIST — On stop: flush pending events, save sync state to disk
🔄 RESUME — On restart: load sync state, replay pending outbound queue
